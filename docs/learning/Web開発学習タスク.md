# Web開発学習タスク

> [!info] 学習目標
> Web開発の基礎からReact・Angularまで学び、実務で役立つスキルを身につける。

## 📚 学習タスク一覧

### STEP 1：HTML・CSSでWebページを作ろう

- [ ] HTMLの基本構造を理解する
- [ ] 見出し・段落・リンク・画像を使う
- [ ] CSSの基本を理解する
- [ ] 色・文字・余白を設定する
- [ ] Flexboxを使う
- [ ] Gridを使う
- [ ] レスポンシブ対応を学ぶ
- [ ] 自己紹介ページを作成する

### STEP 2：JavaScriptでWebページを動かそう

- [ ] JavaScriptの基本を学ぶ
- [ ] 変数・データ型を理解する
- [ ] 条件分岐・繰り返しを学ぶ
- [ ] 関数を理解する
- [ ] 配列・オブジェクトを扱う
- [ ] DOM操作を学ぶ
- [ ] イベント処理を学ぶ
- [ ] Fetch APIを使う
- [ ] 非同期処理を理解する
- [ ] Todoアプリを作成する

### STEP 3：Git・GitHubを使って開発しよう

- [ ] Gitの基本を理解する
- [ ] リポジトリを作成する
- [ ] add・commitを使う
- [ ] push・pullを使う
- [ ] ブランチを作成する
- [ ] mergeを理解する
- [ ] GitHubにコードを公開する
- [ ] READMEを書く

### STEP 4：TypeScriptでより安全なプログラムを書こう

- [ ] TypeScriptの基本を学ぶ
- [ ] 型注釈を理解する
- [ ] interface・typeを学ぶ
- [ ] 配列・オブジェクトの型を設定する
- [ ] Union型を理解する
- [ ] Genericsを学ぶ
- [ ] JavaScriptのアプリをTypeScriptに移行する

### STEP 5：ReactでWebアプリを作ろう

- [ ] Reactの基本を学ぶ
- [ ] JSXを理解する
- [ ] コンポーネントを作成する
- [ ] Propsを理解する
- [ ] Stateを理解する
- [ ] useStateを使う
- [ ] useEffectを使う
- [ ] コンポーネントを分割する
- [ ] React Routerを使う
- [ ] API連携を行う
- [ ] ReactでTodoアプリを作成する

### STEP 6：AngularでWebアプリを作ろう

- [ ] Angularの基本を学ぶ
- [ ] Angular CLIを使う
- [ ] コンポーネントを作成する
- [ ] データバインディングを理解する
- [ ] Servicesを理解する
- [ ] Dependency Injectionを学ぶ
- [ ] Routingを使う
- [ ] Reactive Formsを学ぶ
- [ ] HttpClientを使う
- [ ] AngularでTodoアプリを作成する

### STEP 7：実際の仕事を想定したアプリを作ろう

- [ ] アプリの企画を考える
- [ ] 必要な機能を整理する
- [ ] 画面設計を行う
- [ ] データ設計を行う
- [ ] API連携を実装する
- [ ] 登録・一覧・編集・削除を実装する
- [ ] エラー処理を実装する
- [ ] アプリを完成させる
- [ ] GitHubに公開する

### STEP 8：チーム開発・実務に必要なスキルを身につけよう

- [ ] Pull Requestを作成する
- [ ] コードレビューを理解する
- [ ] テストコードを書く
- [ ] 不具合の調査・修正を行う
- [ ] ESLint・Prettierを使う
- [ ] GitHub Actionsを学ぶ
- [ ] CIの仕組みを理解する
- [ ] アプリをデプロイする
- [ ] README・設計資料を作成する
- [ ] 実務を想定した開発を完了する
