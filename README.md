# pokky-web-learning

Web開発の学習記録とサンプルコードをまとめたリポジトリです。

新人システムエンジニアの「ぽっきー」が、Web開発の基礎から実践的な技術まで、少しずつ学習していきます。

## 🎯 学習目標

- HTML・CSS・JavaScriptの基礎を身につける
- Git・GitHubを使った開発に慣れる
- TypeScriptを使ったプログラミングを学ぶ
- React・Angularを使ったWebアプリ開発に挑戦する
- 実際の開発現場で役立つ知識と技術を身につける

## 📚 ロードマップ

### STEP 1：HTML・CSSでWebページを作ろう

Webページの仕組みと見た目の作り方を学ぶ。

### STEP 2：JavaScriptでWebページを動かそう

ボタンや入力フォームなどの動きを作る。

### STEP 3：Git・GitHubを使って開発しよう

プログラムの保存や変更履歴の管理方法を学ぶ。

### STEP 4：TypeScriptでより安全なプログラムを書こう

間違いを見つけやすく、管理しやすいコードを学ぶ。

### STEP 5：ReactでWebアプリを作ろう

Reactを使ったWebアプリ開発に挑戦する。

### STEP 6：AngularでWebアプリを作ろう

Angularを使ったWebアプリ開発に挑戦する。

### STEP 7：実際の仕事を想定したアプリを作ろう

これまで学んだ技術を使って、本格的なアプリ開発に挑戦する。

### STEP 8：チーム開発・実務に必要なスキルを身につけよう

テスト・レビュー・修正など、開発現場で必要なことを学ぶ。

## 🛠 使用技術

- HTML
- CSS
- JavaScript
- TypeScript
- React
- Angular
- Git / GitHub

## 📖 学習記録

学習した内容や作成したサンプルコードを随時追加していきます。

## 🚀 最終目標

自分でWebアプリを作れるようになり、実際の開発現場で活かせる知識と技術を身につけることを目指します。

焦らず、少しずつ成長していきます！
